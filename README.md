# Paradise Nursery 🌿

## About the Project

Paradise Nursery is a React-based houseplant shopping application where users can explore different indoor plants and manage their shopping cart.

## Features

- Browse houseplants organized into categories.
- View plant names, descriptions, and prices.
- Add plants to the shopping cart.
- Increase or decrease item quantities.
- Remove items from the cart.
- View total items and total price.
- Navigate between Home, Plants, and Cart pages.

## Technologies Used

- React
- Vite
- Redux Toolkit
- React Router
- JavaScript
- CSS

## Installation and Setup

1. Clone the repository.
2. Open the project folder.
3. Install dependencies:

   `npm install`

4. Start the development server:

   `npm run dev`

5. Open the local URL shown in the terminal.
